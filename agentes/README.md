## Como ativar um agente

**No Claude (site ou app do celular) — recomendado para o dia a dia**
1. Abra claude.ai → **Projetos** → **Criar projeto** (ex.: "Conselheiros").
2. Em **Instruções do projeto**, cole o conteúdo do arquivo do agente
   (a parte abaixo de `=== INSTRUÇÕES DO AGENTE ===`).
3. Toda conversa nova dentro desse projeto já fala com o agente.

**No Claude Code**
Os agentes também ficam em `.claude/agents/`. Basta pedir, por exemplo:
"usa o conselheiro-jesus-paulo: tenho uma decisão difícil sobre um sócio".
